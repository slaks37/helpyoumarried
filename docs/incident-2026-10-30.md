## Bukti awal dan batas kesimpulan

- Laporan: GitHub issue #1, Ray ID `a527a71f2adc09ef`, sekitar 11.24 WIB.
- `main` sebelum perbaikan: `1308cca3d479a9952e367b59ac315cc7843f67c5`.
- Vercel menyajikan frontend statis dan me-rewrite API, admin, media serta slug personal ke Worker Sites pada `stefen-jessica-forever-office.stefenlaks.chatgpt.site`.
- Reproduksi HTTP awal dari satu koneksi: `/` dan `/admin` 200; API sesi anonim 401; upstream `/triyono-ribka/` 308 dengan **Location absolut ke chatgpt.site** tanpa no-store. URL dengan slash pada domain utama menghasilkan 404.
- Halaman blok yang dilaporkan belum tereproduksi dari koneksi pengujian. Jangan menyamakan respons 200 satu koneksi dengan pemulihan semua jaringan tamu.
- Akun Cloudflare terhubung tidak memiliki zona `chatgpt.site` atau `stefen-jessica-forever.site`. Worker Sites dan bucket R2 lamanya berada pada akun operator yang berbeda. Akun pengguna hanya menampilkan Worker lain; akses daftar R2 ditolak karena R2 belum diaktifkan pada akun tersebut.
- Log Worker yang tersedia tidak mengidentifikasi aturan WAF untuk Ray ID laporan. Aturan blok yang tepat **belum terverifikasi**. Log mentah, IP tamu, cookie dan token tidak disertakan dalam laporan ini.

## Mitigasi kode

1. Canonical redirect menggunakan Location relatif dengan query token tetap utuh. Tidak mempercayai forwarded host untuk membuat redirect; path yang berpotensi menghasilkan redirect protocol-relative ditolak.
2. Header browser/CDN no-store dipasang setelah respons aset pada undangan personal, admin, API, redirect, cookie dan galat.
3. CSP hanya mengizinkan koneksi same-origin; frontend tidak perlu menghubungi hostname upstream langsung.
4. Vercel meneruskan URL dengan trailing slash ke canonical redirect Worker yang relatif dan no-store, meneruskan `/admin.html` ke handler autentikasi, dan menonaktifkan rewrite caching pada rute dinamis, termasuk jika upstream mengembalikan halaman galat sebelum Worker.
5. Origin tetap dipertahankan; tidak ada origin pengganti yang ditebak, perubahan WAF, rotasi kredensial, migrasi database atau perubahan data tamu.

Mitigasi ini memperbaiki cacat routing/cache. **Mitigasi ini tidak menghapus WAF operator chatgpt.site dan tidak menjamin blok Ray ID laporan selesai.**
